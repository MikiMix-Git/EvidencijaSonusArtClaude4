# EvidencijaSonusArt

Analiza bankovnih izvoda (React + TypeScript + Vite + Tailwind). Izvodi i pravila grupisanja se čuvaju lokalno u SQLite fajlu `data/evidencija.db`.

## Pokretanje
```bash
npm install
npm run dev      # http://localhost:3000
```
Putanju baze možeš promijeniti preko varijable `SONUS_DB_PATH`.
